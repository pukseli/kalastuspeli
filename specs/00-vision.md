# 00 — Visio ja Suunnittelun Peruspilarit

| Osio | Sisältö |
| :--- | :--- |
| **Elevator pitch** | 3–4 pelaajan humoristinen ja hektinen 3D-uistelupeli järvellä. Overcooked × Sea of Thieves -henkinen tiimikaaos. |
| **Ydinrytmi** | "Tyyntä myrskyn edellä": leppoisaa puuhastelua, kunnes AI Director laukaisee kaaospiikin, jossa kaikki tapahtuu yhtä aikaa (tuplatärpit, siimasotkut, karikot, haavin etsiminen, moottoriongelmat). |
| **Suunnittelun peruspilarit** (**LUONNOS, käyttäjä vahvistaa**) | 1. **Tiimityö pakottaa kommunikoimaan.** Yksi ei ehdi kaikkea.<br>2. **Kaaos on hauskaa, ei turhauttavaa.** Epäonnistuminen naurattaa.<br>3. **Helppo oppia, sohvalta pelattava.** Vähän näppäimiä.<br>4. **Pyörii perunalla.** Low-poly, ei raskaita efektejä. |
| **Non-goals** | Realistinen kalastussimulaattori · fotorealistinen grafiikka · raskas fysiikkasimulaatio · yksinpelikeskeisyys |
| **Kohdealusta** | PC (Linux/Windows), integroitu GPU (ks. `00-environment.md`) |

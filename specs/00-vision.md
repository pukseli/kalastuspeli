# 00 — Visio ja Suunnittelun Peruspilarit

| Osio | Sisältö |
| :--- | :--- |
| **Elevator pitch** | 3–4 pelaajan humoristinen ja hektinen 3D-uistelupeli järvellä. Overcooked × Sea of Thieves -henkinen tiimikaaos. |
| **Ydinrytmi & Tehtäväsaturaatio** | "Tyyntä myrskyn edellä" + **tehtäväsaturaatio**: asioita tapahtuu yhtä aikaa enemmän kuin yksi tai kaksi pelaajaa pystyy hallitsemaan. Kaaos syntyy ketjureaktioista: 6 vavan uistelu, tärppivavan pujottaminen ulommaiseksi (`-1 → -3`) ilman sotkua, haavitus ulkolaidalta, veneen jatkuva liike aallokossa/tuulessa ja karikoiden väistö (pysähdys tai törmäys sotkee siimat). |
| **Suunnittelun peruspilarit** | 1. **Tiimityö pakottaa kommunikoimaan.** Yksi ei ehdi kaikkea; kameroiden epäsymmetria (ruori katsoo eteen, kansi taakse) pakottaa huutamaan tilannetiedot.<br>2. **Kaaos on hauskaa, ei turhauttavaa.** Ketjureaktiot ja epäonnistuminen naurattavat.<br>3. **Helppo oppia, sohvalta pelattava.** Vähän näppäimiä (`WASD` + 2–3 toimintopainiketta).<br>4. **Pyörii perunalla.** Low-poly, kevyt matemaattinen fysiikka, ei raskaita efektejä. |
| **Kehitysfilosofia** | Ensin netcode ja perusfysiikat kuntoon, sitten ydinpelimekaniikat tärkeysjärjestyksessä ja vasta lopuksi "väriä" (3D-viimeistely, UI, palaute). Toteutus pidetään avoimena ja geneerisenä tuleville kaaoskerroksille. |
| **Non-goals** | Realistinen kalastussimulaattori · fotorealistinen grafiikka · raskas fysiikkasimulaatio · yksinpelikeskeisyys |
| **Kohdealusta** | PC (Linux/Windows), integroitu GPU (ks. `00-environment.md`) |
